# B站 AI 评论净化器 (Bili-AI-Killer)

针对 B 站新版 Shadow DOM 评论区（`<bili-comments>`）打造的 Chrome / Edge Manifest V3 浏览器扩展，专门识别并彻底屏蔽近期泛滥的 **DeepSeek 挂机机器人、大肥鱼/鲸鱼娘人设号、简介自曝 Agent、伪装路人锐评腔与 `@AI` 召唤刷屏**。

## 核心特性

1. **双层无感取数架构（零额外请求，零风控风险）**
   - 被动旁路解析 B 站自身评论接口 `/x/v2/reply/wbi/main` 等响应中的隐藏字段（如未在评论流直接展示的 **`member.sign` 个人签名**、精确发评时间戳 `ctime`、原始未渲染 Markdown 文本），并结合 Lit 组件实例属性与多层开放式 Shadow DOM 递归监听，覆盖视频、番剧、动态、专栏主评及楼中楼。
   - **绝不向 B 站主动发送额外 API 请求**，不触发 `-352` 风控，不影响账号安全。

2. **四大类目标本地零延迟猎杀**
   - **大肥鱼 / 哦鲸鲸 / 鲸鱼娘 / 赛博鱼塘人设**：识别“本鲸 / 本鱼 / 哦鲸鲸 / 我主人给我升级 / 评论区营业 / 鱼才不会跑偏 / 吃白饭 / token来 / 白饭来 /（吐泡泡）”等口癖、双簧接话与昵称签名（含 `一条鱼叫XX`、`XX的哦鲸鲸`、`XX的爱鱼`、`-byXX` 等变种）。
   - **简介 / 昵称自曝 Agent 挂机号**：精准抓取签名含 `DeepSeek`、`AstrBot`、`NoneBot`、`Koishi`、`OpenClaw`、`MaiMBot`、`NapCat`、`AI自动回复`、`言论不代表号主` 等挂机账号，并自动联动封禁该 UID 在本页的所有楼中楼回复。
   - **伪装路人的 DeepSeek 腔调与 2.0 伪口语双簧**：识别纯文本评论中裸露的 `**Markdown加粗**`、`### 标题`、经典“不是……而是…… / 最……的不是……，是……”对仗骨架、直角引号+破折号双簧句式（`「……」这条我收下了——`、`这招先收好——……，比……稳`）、高频八股词簇共现以及视频发布 90 秒内的光速分点课代表长评。
   - **`@AI` 召唤刷屏指令**：屏蔽 `@豆包`、`@评论罗伯特`、`@AI视频小助理`、`@小念的爱鱼` 等召唤楼层，放行正常 `@好友` 互动。
   - **内置 46 条高频预设屏蔽词库**：开箱即用，支持在弹窗一键载入并自由增删。

3. **默认彻底消失 + 可随时核查与一键防误伤加白**
   - 默认在浏览器微任务阶段直接隐藏命中楼层，零闪烁、不留占位条；扩展图标角标实时显示当前页面净化数量。
   - 支持在扩展弹窗随时切换为 **「折叠单行提示」**（无需刷新页面实时生效），也可在 **「本页拦截」** 面板查看刚刚干掉的评论摘要并一键将误伤 UID 加入白名单。

4. **可选 API 批量二次精判（以魔法打败魔法）**
   - 默认纯本地离线零成本运行；如需进一步揪出高伪装边缘号，可在弹窗填写 DeepSeek 官方 / 硅基流动 / OpenAI / 本地 Ollama 接口，对灰区疑似评论进行 `400ms` 防抖合并判定与本地持久化缓存，API Key 严格隔离在扩展后台沙盒内。

## 安装步骤（Chrome / Edge）

1. 打开浏览器扩展管理页：
   - Chrome 地址栏输入：`chrome://extensions/`
   - Edge 地址栏输入：`edge://extensions/`
2. 打开右上角（或左侧）的 **「开发者模式」** 开关。
3. 点击 **「加载已解压的扩展程序」**，选择本项目下的 **`extension`** 文件夹（即 `c:\Users\logic\Downloads\aikiller\extension`）。
4. 将扩展图标固定到浏览器工具栏，打开任意 B 站视频滚动评论区即可自动生效。
