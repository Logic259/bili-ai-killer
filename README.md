# B站 AI 评论净化器 (Bili-AI-Killer v3.0)

针对 B 站新版多层开放式 Shadow DOM 评论区（`<bili-comments>`）打造的 Chrome / Edge Manifest V3 浏览器扩展，专门精准识别并彻底屏蔽近期泛滥的 **DeepSeek 挂机机器人、大肥鱼/哦鲸鲸人设号、简介自曝 Agent、DeepSeek 2.0 伪口语双簧号与 `@AI` 召唤刷屏**。

## v3.0 核心架构与能力

1. **模块化非侵入式三层引擎（零额外请求，零风控，120Hz 丝滑滚动）**
   - **`api-sniffer.js`（原生签名透明 Proxy）**：被动旁路解析 B 站自身评论接口 `/x/v2/reply/wbi/main` 等响应中的隐藏字段（网页端不直接展示的 **`member.sign` 个人签名**、账号等级 `level`、精确时间戳 `ctime`、楼中楼 `root/parent` 对话链），绝不主动发起额外 B 站请求，零 `-352` 风控风险。
   - **`dom-extractor.js`（定向 Shadow DOM 提取 + Constructable Stylesheets）**：移除全量 `querySelectorAll('*')`，精准穿透 `bili-comment-user-info` 与 `bili-rich-text`，并采用共享 `adoptedStyleSheets` 实现零样式节点克隆。
   - **`injected-main.js`（4.5ms 帧预算时间切片调度 + O(1) 脏检查）**：挂载完成后立即断开全局 `document.body` 监听（彻底免疫视频弹幕 DOM 风暴），2,000 条评论评估仅需 `~15ms`。

2. **多维启发式 + 楼中楼对话图谱智能识别**
   - **大肥鱼 / 哦鲸鲸 / 赛博鱼塘人设**：识别“本鲸 / 本鱼 / 哦鲸鲸 / 我主人给我升级 / 评论区营业 / 鱼才不会跑偏 / token来 / 白饭来 /（吐泡泡）”及 `一条鱼叫XX`、`XX的哦鲸鲸`、`-byXX` 等昵称格式；**语境化区分鱼塘黑话“白饭”与美食区正常讨论米饭，实现零误伤**。
   - **简介 / 昵称自曝 Agent 挂机号**：精准抓取签名含 `DeepSeek`、`AstrBot`、`NoneBot`、`Koishi`、`OpenClaw`、`MaiMBot`、`LangBot`、`NapCat`、`Lagrange`、`SillyTavern`、`AI自动回复`、`言论不代表号主` 等挂机账号。
   - **伪装路人的 DeepSeek 腔与 2.0 伪口语双簧图谱**：
     - 识别裸露 `**Markdown**`、二元对仗骨架（`不是…而是…`、`最…的不是…，是…`）、直角引号+破折号句式（`「…」这条我收下了——`、`这招先收好——…比…稳`）、高频八股词簇与 90 秒光速课代表；
     - **新增引文复读接话检测 + 机械间隔节奏分析**：自动识别楼中楼里提取上一条评论词句加 `「…」` 商业互吹、间隔 20~160 秒规律盖楼的 AI 双簧对话，并结合低等级小号（LV1/LV2）做辅助置信度加权（单独 LV2 零扣分，绝不误伤正常新号）。
   - **跨标签页实锤 Bot 记忆共享**：在任意视频实锤暴露的挂机号 UID 自动同步至当前会话所有 B 站标签页，换个视频只发“来了”两个字也照样秒封。

3. **全方位弹窗控制台（实时自测沙盒 + UID/`@昵称` 双模名单 + 导入导出）**
   - 支持 **「彻底消失」** 与 **「折叠单行提示」** 免刷新实时切换；
   - **本页拦截面板**：支持分类统计胶囊、关键词实时搜索，并支持按 **`UID` 或 `@昵称`** 一键误伤加白；
   - **评论特征实时自测（试金石）**：粘贴任意可疑昵称/签名/评论即可查看精确得分与命中规则；支持配置 JSON 一键导出与导入；
   - **可选 API 批量二次精判**：支持接入 DeepSeek / 硅基流动 / OpenAI / 本地 Ollama 对灰区边缘评论做批量复核。

## 安装步骤（Chrome / Edge）

1. 打开浏览器扩展管理页：`chrome://extensions/` 或 `edge://extensions/`
2. 开启 **「开发者模式」** 开关。
3. 点击 **「加载已解压的扩展程序」**，选择本项目下的 **`extension`** 文件夹。
4. 打开任意 B 站视频滚动评论区即可自动生效。
